# 회로 실험실 (Circuit Lab) — 센서 로봇 프로젝트

중학교 2학년 기술·가정 「센서 로봇 프로젝트」 Ⅰ영역(회로 이해 및 설계) 수업용 회로 시뮬레이터.
단일 `index.html` 파일로 동작하며 iPad(Safari)·PC 브라우저에서 계정 없이 사용합니다.

## 기능
- 회로도 형식(브레드보드 아님) · 부품 8종: 건전지, 스위치, 자기 센서, 기울기 센서, 저항, LED, 모터, 부저
- 단자 ○를 두 번 눌러 전선 연결(터치 최적화), 부품 끌기·회전·뒤집기(＋−)·삭제
- ▶ 전류 보기: 완성된 회로에 전류가 흐르는 애니메이션 (PhET 방식)
- 판정: 합선 경고 · LED 역방향 경고 · 저항 없는 LED 경고 · 모터 회전 방향 · 부저 소리
- 모드: 자유 구성 / 학습지1 예제 2·3 / 학습지2 예제 1·2·3 (학습지와 1:1 대응, 정답 확인 버튼)

## GitHub Pages 배포
1. GitHub에 새 저장소 `Circuit` 생성 (Public)
2. `index.html`을 저장소 루트에 업로드 (README.md는 선택)
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 1~2분 후 `https://techtkim.github.io/Circuit/` 에서 접속

## 수업 흐름 예시
- 1차시(학습지 1): 기호·역할 → 1-② 직렬 회로 완성(스탠드) → 1-③ 자기 센서 알림등 만들기
- 2차시(학습지 2): 2-① 직렬·병렬 비교 관찰 → 2-② 병렬 회로 완성(조명+컵 경고) → 2-③ 병렬 회로 설계(보관함)
- 평가(Ⅰ영역 평가지): 기호 그리기 / 손전등 직렬 회로도 / 넘어짐 경고 원리 / 현관 알림 병렬 설계
